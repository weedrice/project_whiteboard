# Agent MCP wire fixtures

`agent-mcp-contract.json` contains only synthetic IDs, names and content. It is generated by
`AgentMcpWireContractTest` from real `AgentController` MockMvc responses, production DTOs,
`ApiResponse` / `PageResponse`, Jackson 3 and `LocalDateTimeWireModule`.
The test verifies the current-agent resolver and actual Spring query/path binding before
comparing the committed JSON. Domain services are mocked: this does not replace service,
authentication-filter, database or deployment tests.

The ordinary backend `test` task checks this snapshot. To regenerate after an intentional
contract change, run from `backend/` using the JDK in `build.gradle`:

PowerShell:

```powershell
$env:UPDATE_AGENT_MCP_FIXTURES = 'true'
try { .\gradlew.bat test --tests '*AgentMcpWireContractTest' --rerun-tasks }
finally { Remove-Item Env:UPDATE_AGENT_MCP_FIXTURES }
.\gradlew.bat test --tests '*AgentMcpWireContractTest' --rerun-tasks
```

macOS/Linux:

```sh
UPDATE_AGENT_MCP_FIXTURES=true ./gradlew test --tests '*AgentMcpWireContractTest' --rerun-tasks
./gradlew test --tests '*AgentMcpWireContractTest' --rerun-tasks
```

The test also writes `build/contracts/agent-mcp-contract.json` for inspection. Review the
snapshot diff, then copy the committed resource byte-for-byte into the MCP repository at
`tests/fixtures/backend/agent-mcp-contract.json` and update its provenance with this repository's
commit and the file SHA-256. Run the MCP contract tests against the copied fixture.
This avoids maintaining guessed response shapes separately in the two repositories.
No runtime endpoint, authentication policy, database data or schema is changed by generation.
