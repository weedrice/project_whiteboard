# Tag 도메인 가이드

`tag` 도메인은 게시글 태그 연결, 인기 태그 조회, 고아 태그 정리를 담당합니다.

## 1. 주요 기능 및 로직

- 태그 처리: 게시글 저장/수정 시 기존 태그를 비교하여 삭제하거나 신규 태그를 생성/연결하고 `post_count`를 갱신합니다.
- 태그 생성: `TagRepository.insertIgnore()`로 현재 게시글 command 트랜잭션 안에서 생성하고, 중복 생성 race는 잠금 재조회로 복구합니다.
- 고아 태그 정리: 매일 03:20 KST에 `post_count = 0`, `post_tags` 연결 없음, 생성 후 24시간 초과 조건을 모두 만족하는 태그만 삭제합니다.
- 삭제 경계: 생성 후 정확히 24시간인 태그는 삭제하지 않고, 24시간을 초과한 태그부터 정리합니다.
- 태그 추천: 게시글 작성 내용과 사용자 문맥을 바탕으로 추천 태그를 반환합니다.

## 2. API Endpoints

| Method | URI | 설명 |
| :----- | :---------------------------------- | :--------------------------- |
| `GET` | `/api/v1/tags` | 인기 태그 목록 |
| `POST` | `/api/v1/tags/suggestions` | 게시글 작성용 태그 추천 |
| `GET` | `/api/v1/tags/{tagKey}/posts` | 태그 이름 또는 숫자 ID로 게시글 목록 조회 |

## 3. 관련 DB 테이블

| 테이블명 | 엔티티 | 설명 |
| :------- | :----- | :--- |
| `tags` | `Tag` | 태그 이름과 사용 수 |
| `post_tags` | `PostTag` | 게시글-태그 매핑 |
