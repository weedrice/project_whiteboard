# Sanction 도메인 가이드

`sanction` 도메인은 사용자 제재(정지/경고) 기록과 조회를 관리합니다.

## 1. 주요 기능 및 로직
- 제재 생성: 슈퍼관리자 권한으로 대상 사용자에 제재 유형(WARNING/MUTE/BAN)과 기간/비고를 등록합니다.
- **BAN**: 등록 시 즉시 계정 상태를 정지(`User.suspend()`)합니다.
- **MUTE / WARNING**: DB에 이력만 저장하며, **별도 시행 로직 없음**. (예: MUTE 기간 동안 게시/댓글 금지 등 미구현)
- 제재 조회: 전체 또는 특정 사용자의 제재 이력을 페이지 단위로 조회합니다.
- 차단 여부 확인: `isUserBanned()`로 현재 유효한 BAN 제재 존재 여부를 확인합니다.

## 2. API Endpoints

| Method | URI | 설명 |
| :----- | :------------------------------------ | :--------------------- |
| `POST` | `/api/v1/admin/sanctions` | 사용자 제재 등록 |
| `GET` | `/api/v1/admin/sanctions` | 제재 이력 조회(필터 지원) |

## 3. 관련 DB 테이블

| 테이블명 | 엔티티 | 설명 |
| :------- | :----- | :--- |
| `sanctions` | `Sanction` | 제재 유형/기간/관리자/대상 사용자 |
