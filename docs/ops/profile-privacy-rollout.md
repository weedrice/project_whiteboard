# 프로필 비공개 설정 단계적 활성화

상태: 구현 반영. 운영 배포와 활성화는 아직 수행하지 않았다.

## 적용 계약

V100은 공개 설정 컬럼 세 개와 `global_configs.PROFILE_PRIVACY_ENABLED=N`을 추가한다.
이 플래그는 **설정 변경의 허용 여부**만 제어한다. 저장된 `N` 값의 조회 제한은 플래그와 무관하게 적용한다.
플래그가 없거나 값이 `Y`가 아니면 설정 변경은 비활성이다. 일반 환경설정 조회는
`profilePrivacyEnabled=false`를 반환하고 프런트는 공개 범위 입력을 숨긴다.
비활성 상태에서 세 공개 필드 중 하나라도 명시한 수정 요청은 HTTP 403 / `U013`으로 전체 거부한다.
공개 필드를 생략한 테마·언어 등의 저장은 계속 가능하다.

관리 API는 플래그에 Y/N 값만 허용하고, `Y`에서 `N`으로 되돌리는 변경과 키 삭제를 금지한다.
이 설정은 공개 전역 설정 API에 노출하지 않는다. 내 환경설정 API의 활성화 여부만 사용자에게 전달한다.

## 1단계: 지원 코드 배포, 비공개 저장 비활성 유지

대상은 운영자가 승인한 환경이다. 이 문서 자체는 운영 변경의 실행 승인이 아니다.
기존 [배포 워크플로](../../.github/workflows/README.md)와 [마이그레이션 정책](database-migration-policy.md)을 따른다.

1. V100과 비공개 조회 제한을 지원하는 백엔드 및 프런트엔드를 배포한다. 플래그는 `N`을 유지한다.
2. 슈퍼 관리자 권한으로 `GET /api/v1/configs/PROFILE_PRIVACY_ENABLED`를 조회해 `N`을 확인한다.
   내 환경설정 응답의 `profilePrivacyEnabled=false`, 공개 설정 UI 미노출도 확인한다.
3. 개인정보 설정을 새로 저장할 수 없는 동안 기존 JAR로의 정상 롤백을 허용한다.
   이미 비공개 데이터가 존재하는 환경에는 이 전제가 성립하지 않으므로 구버전으로 롤백하지 않는다.

## 2단계: 구버전 롤백 기간 종료 후 활성화

다음 조건을 **모두** 확인하고 배포 기록에 현재 SHA와 허용할 복구 대상 SHA를 남긴다.

- 현재 서비스와 모든 허용된 자동·수동 복구 대상이 저장된 공개 범위를 준수하는 버전이다.
- 특히 현재 배포가 남긴 `/opt/app/backend/app.jar.rollback`이 구버전이면 아직 활성화하지 않는다.
  비공개 조회 제한을 지원하는 버전을 후속 배포하여 이전 JAR도 지원 버전이 되게 하고 검증한다.
- 프로필 공개 범위를 무시하는 버전은 이후 롤백 대상으로 사용하지 않도록 운영 복구 기준에 기록한다.
- 새 버전의 상태 확인과 본인·다른 회원·비로그인 조회 검증이 완료됐으며, 구버전으로 복구할 기간이 끝났다.

조건을 충족한 환경에서만 슈퍼 관리자가 다음 요청을 실행한다. 기존 관리자 설정 화면에서도 같은 키를 변경할 수 있다.

```http
PUT /api/v1/admin/configs/PROFILE_PRIVACY_ENABLED
Content-Type: application/json

{"value":"Y"}
```

성공 후 관리자 조회 값 `Y`, 내 환경설정 `profilePrivacyEnabled=true`, 설정 화면 노출을 확인한다.
승인된 검증 계정으로 비공개를 저장하고 본인은 조회 가능하며 다른 회원·비로그인은 해당 영역에
`U012`를 받는지 확인한다. 활성화는 단방향이며, 배포나 마이그레이션이 자동으로 활성화하지 않는다.

## 활성화 이후 복구

비공개 설정을 무시하는 JAR로 복구하거나 플래그·사용자 값을 SQL로 되돌리지 않는다.
허용된 지원 버전으로만 롤백하며, 해당 버전으로 복구할 수 없으면 접근을 중단하고 지원 코드를 수정 배포한다.
플래그가 손상되거나 누락돼도 지원 코드의 읽기 제한은 유지되지만, 이는 비지원 구버전을 안전하게 만들지는 않는다.
다른 마이그레이션의 `contract_migration=true`에 의존해 이 절차를 생략하지 않는다.

- `frontend/e2e/profile-privacy.spec.ts`: 활성화 여부에 따른 화면·요청과 프로필 접근 제한
