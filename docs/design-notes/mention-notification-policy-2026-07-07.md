# NoviIs 멘션 알림 정책

작성일: 2026-07-07

현행 확인: 2026-07-17

## 공통 정책

- 한 게시글 또는 댓글에서 같은 사용자를 여러 번 멘션해도 알림은 한 번만 보낸다.
- 작성자 자신, 비활성·탈퇴 사용자, 작성자와 차단 관계인 사용자는 알림 대상에서 제외한다.
- 한 콘텐츠에서 알림 수신자는 최대 10명이다.
- 알림은 콘텐츠 생성 트랜잭션이 성공한 경우에만 발행한다.

## 게시글

- 게시글 생성 시 저장된 HTML의 `data-mention-user-id`를 기준으로 멘션 알림을 보낸다.
- 게시글 수정 시에는 멘션 알림을 새로 보내거나 재발송하지 않는다.

## 댓글

- 댓글 생성 시 `mentionedUserIds`가 있으면 해당 목록을, 없으면 본문 HTML의 `data-mention-user-id`를 기준으로 알림을 보낸다.
- 선택된 멘션 사용자는 `comment_mentions`에 저장하고 댓글 응답의 `mentions`로 제공한다.
- 댓글 수정 시 명시적인 멘션 목록이 전달되면 표시용 `comment_mentions`만 교체한다. 목록이 없으면 기존 메타데이터를 유지하고, 빈 목록이면 모두 제거한다.
- 댓글 수정은 신규 또는 기존 멘션 알림을 발송하지 않는다.

수정에서 새로 추가된 사용자에게만 알림을 보내는 정책은 현재 계약이 아니다. 도입하려면 이전·신규 수신자 차집합, 중복 이벤트 방지, 재시도 멱등성을 별도 설계하고 API·서비스 테스트를 함께 변경한다.
