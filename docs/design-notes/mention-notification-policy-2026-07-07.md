# NoviIs 멘션 알림 정책

작성일: 2026-07-07

현행 확인: 2026-08-13

## 공통 정책

- 한 게시글 또는 댓글에서 같은 사용자를 여러 번 멘션해도 알림은 한 번만 보낸다.
- 작성자 자신, 비활성·탈퇴 사용자, 작성자와 차단 관계인 사용자는 알림 대상에서 제외한다.
- 한 콘텐츠에서 알림 수신자는 최대 10명이다.
- 알림은 콘텐츠 생성·수정 트랜잭션이 성공한 경우에만 발행한다.

## 게시글

- 게시글 생성 시 저장된 HTML의 `data-mention-user-id`를 기준으로 멘션 알림을 보낸다.
- 게시글 수정 시 이전 HTML과 수정 HTML의 멘션 사용자 차집합을 계산해 새로 추가된 사용자에게만
  알림을 보낸다. 기존 멘션은 재발송하지 않고 제거된 멘션도 알림을 만들지 않는다.

## 댓글

- 댓글 생성 시 `mentionedUserIds`가 있으면 해당 목록을, 없으면 본문 HTML의 `data-mention-user-id`를 기준으로 알림을 보낸다.
- 선택된 멘션 사용자는 `comment_mentions`에 저장하고 댓글 응답의 `mentions`로 제공한다.
- 댓글 수정 시 명시적인 멘션 목록이 전달되면 `comment_mentions`를 교체하고 이전·현재 사용자
  차집합에 새로 들어온 사용자에게만 알림을 보낸다. 기존 멘션은 재발송하지 않는다.
- 수정 요청에 멘션 목록이 없으면 기존 메타데이터를 유지하고 새 알림도 만들지 않는다. 빈 목록이면
  저장된 멘션을 모두 제거하며 제거 알림은 만들지 않는다.

수정에서 새로 추가된 사용자에게만 알림을 보내는 것이 현재 계약이다. `MentionService`가 이전·현재
수신자를 정규화한 뒤 차집합만 발행하며, 게시글·댓글 수정 서비스와 멘션 서비스 테스트가 이 동작을
고정한다.
